# 微信签到抽奖项目需求整理

## 输入来源

- 原始需求：`docs/source-ppt/需求PPT.pptx`
- 参考页面：https://www.shulehudong.com/gongneng/xianchanghudong/44.html

## PPT 提取到的需求

1. 大屏可上传公司 Logo，Logo 和签到二维码支持拖动摆放。
2. 中间区域展示已签到人员微信头像，可组成几何图形旋转，也可输入文字组成文字造型。
3. 已签到人员信息从屏幕边缘飞入，中间展示后退场。
4. 大屏底部有操作栏，背景音乐可后台上传，每个页面可设置不同音乐。
5. 抽奖可在后台上传奖品信息，设置总中奖人数。
6. 抽奖时需要有滚动动画和停止按钮，中奖人员弹窗展示，关闭后进入获奖名单。
7. 内网可用即可：一台电脑运行，同一网络输入 IP 和端口访问。
8. 登录后本浏览器窗口内不失效，关闭浏览器后重新登录；登录时选择“大屏”或“后台”。
9. 签到需获取微信头像、昵称等数据；签到时填写姓名、所在单位、手机号。
10. 所在单位可由后台预设为下拉选项。
11. 签到数据可导出 Excel。
12. 抽奖必须从已签到人员中抽取。
13. 支持内定中奖人员。
14. 后台可设置奖品类型、图片、数量。
15. 中奖数据可导出 Excel。

## 参考页面补充

参考页面强调 3D 头像滚动抽奖、无公众号也可扫码参与、大屏背景和 Logo 自定义、每个奖项可配置不同动画、支持一次抽多人、默认过滤已中奖用户、可按分组抽奖。当前第一版已实现其中的扫码参与、Logo 自定义、头像滚动、每次抽取人数、过滤已中奖用户、奖项配置和数据导出；分组抽奖作为后续增强项预留。

## 当前实现范围

### 已实现

- 本地 Web 服务，支持局域网访问。
- 登录入口：后台 / 大屏，使用 `sessionStorage` 保持到浏览器窗口关闭。
- 手机签到页：微信或浏览器扫码进入，填写昵称、姓名、单位、手机号。
- 签到二维码：大屏和后台均可展示。
- 实时大屏：签到后通过 WebSocket 同步，人员卡片飞入。
- 头像墙：球形、矩阵、文字造型三种布局。
- Logo 和二维码拖拽：拖动后保存到后台配置。
- 背景音乐上传和大屏播放。
- 后台奖项管理：奖项名称、图片、名额、每次抽取人数、动画方式。
- 内定中奖：每个奖项可选择内定人员。
- 滚动抽奖：从已签到人员中抽取，默认过滤已中奖人员。
- 中奖弹窗和获奖名单。
- 签到数据 / 中奖名单 Excel 导出。
- 演示签到数据生成，便于现场彩排。

### 预留/待接入

- 微信 OAuth 自动获取头像、昵称：需要公众号或开放平台的 AppID、AppSecret、网页授权域名。
- 分组抽奖：当前单位字段已可作为分组基础，下一版可增加每组抽取人数配置。
- 背景视频：当前实现背景音乐和红金主题背景，视频背景可继续扩展。
