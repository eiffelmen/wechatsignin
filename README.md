# 微信签到抽奖 Web 项目

本项目用于内网活动现场：电脑启动服务，大屏展示二维码，来宾用微信扫码签到，后台管理奖项并发起滚动抽奖。

图文使用手册：[PDF 阅读版](docs/user-guide/微信签到抽奖系统使用手册.pdf) / [Word 编辑版](docs/user-guide/微信签到抽奖系统使用手册.docx)。

## 启动

```bash
npm install
npm start
```

默认端口：`3000`

打开：

- 登录页：http://localhost:3000
- 后台：http://localhost:3000/admin
- 签到展示：http://localhost:3000/screen/checkin
- 抽奖大屏：http://localhost:3000/screen/lottery
- 手机签到：http://localhost:3000/checkin

同一局域网手机访问时，用服务启动后打印的 `http://本机IP:3000` 地址。
如果电脑用 `localhost` 打开后台或大屏，系统会优先把签到二维码生成为局域网 IP 地址；也可以通过 `PUBLIC_URL=http://本机IP:3000 npm start` 手动指定。

## 默认密码

- 后台：`admin123`
- 大屏：`screen123`

登录状态保存在当前浏览器窗口，关闭浏览器后需要重新登录。

## 已实现能力

- 独立签到展示页：二维码、签到人数、头像墙和最近签到实时更新。
- 独立抽奖页：选择奖项和人数，开始后持续播放头像滚动动画，点击停止后揭晓中奖人。
- 微信扫码签到入口，二维码默认使用局域网签到地址。
- 默认使用内网表单签到：只填姓名，头像可上传，也可自动生成姓名头像，无需公众号或公网域名。
- 大屏二维码和 Logo 可拖动摆放，二维码支持拖动手柄或 `+` / `-` 按钮缩放，松手或点击后自动保存。
- 每个奖项可以设置球形、环绕、头像墙或文字抽奖动画。
- 中奖弹窗关闭后，结果保留在当前奖项的抽奖结果中；切换一、二、三等奖时，只显示对应奖项的记录。
- 抽奖结果和展开名单均按当前奖项筛选，后台数据导出保留所有奖项。
- 签到数据和中奖数据可导出 Excel。

`/screen` 兼容旧版抽奖入口。两个大屏页面使用相同的大屏密码，底部导航可互相切换。

## 内网扫码签到

默认签到方式是“内网填写姓名与头像”，可在后台“页面设置”的“签到方式”中选择。

1. 服务器或电脑启动项目，并放行服务端口（默认 `3000`，本地预览使用 `3100`）。
2. 手机连接能访问服务器的现场 Wi-Fi；访客隔离、防火墙规则不能阻止手机访问服务。
3. 打开签到展示页，手机用微信扫一扫扫描二维码。
4. 来宾填写姓名，可选上传照片，不上传则使用自动生成的姓名头像；无需手机号。
5. 提交后自动上墙并进入抽奖名单。再次打开同一地址会显示已签到，可修改姓名和头像。

照片在浏览器内裁成方形、压缩到最长 `512` 像素后上传到本地服务器。支持 JPG、PNG、WebP、GIF，原图不超过 `12 MB`，生成的上传文件不超过 `2 MB`。

重复提交按当前浏览器保存的访客标识更新同一条记录，不按姓名去重；不同来宾同名不会被合并。更换设备、切换浏览器或清除浏览器数据后，不能据此识别是否为同一个人。

纯内网签到不会读取微信头像和昵称。手机页面、照片存储、签到数据和大屏同步均由本项目提供，不依赖外部服务。

## 可选微信授权

后台将“签到方式”切换为“微信网页授权”后，仍可使用已有公众号授权流程：来宾授权后获取微信 `openid`、昵称和头像并完成签到。

启动前设置以下环境变量：

```bash
WECHAT_APP_ID=你的公众号AppID \
WECHAT_APP_SECRET=你的公众号AppSecret \
PUBLIC_URL=https://你的公网域名 \
npm start
```

要求：

- `PUBLIC_URL` 必须是微信能访问到的公网 HTTPS 域名。
- 在微信公众号后台配置“网页授权域名”，域名与 `PUBLIC_URL` 保持一致。
- 回调地址为：`PUBLIC_URL/wechat/oauth/callback`
- 默认授权范围为 `snsapi_userinfo`，用于获取头像和昵称。

只有选择“微信网页授权”且缺少上述配置时，才会提示“微信授权未配置”；默认内网模式不需要这些配置。
